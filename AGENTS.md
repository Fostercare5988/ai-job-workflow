# Public demonstration workspace

Read README.md (or README.da.md) and FRAMEWORK.md first. All runnable applicant
and vacancy records are synthetic. The approved personal presentation in
docs/case.*.md and docs/assets/ describes Niko's real project and includes only
the contact details he authorised for that presentation. Do not import private
data, application receipts or real requests into the demo.

Run `python tools/jobflow.py check` and `python tools/jobflow.py next` to orient.
`python demo.py reset` explicitly regenerates the disposable fixture, including
its synthetic review; it is not a real review workflow.

One responsible assistant owns Data/jobs.json. Delegated tasks get separate file
ownership. Review actual sources and output rather than another agent's summary.
Keep claims specific, attribute AI assistance, and stop after three concrete
correction rounds if an issue persists.

For actual content work, fill templates/review.json after reading the sources.
Never auto-pass review checks or replace hashes just to remove a failure.
Do not send applications or messages: this repository provides no such tool.

This snapshot is separate from the original private workspace. The public
manifest and default-deny ignore file are publication boundaries, not permission
to publish any newly added file.
