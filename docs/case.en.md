# AI you can put to work

Niko Nikolic · IT Technology graduate · Copenhagen

It's easy to ask AI to write an application. I wanted to keep track of the whole task: find relevant jobs, use my actual experience, and keep documents and status in order. That's what my job-search project is designed to do.

## My case: from job preferences to an application pack

The assistant needs to find relevant roles and use my actual experience. Work must be easy to resume, and the overview needs to show what is ready and what has actually been sent.

## Four steps in the workflow

1. **Define the task.** My preferences and documented experience set the direction.
2. **Let AI do the groundwork.** The assistant researches jobs and writes tailored documents.
3. **Run checks.** The tools flag possible duplicates, missing files and changes.
4. **Review and continue.** I read the documents. Status and the next step are saved.

## The concrete result

For each selected job, the documents are collected so I can review them and decide whether to apply.

- **CV:** Relevant experience and projects tailored to the role.
- **Application:** Motivation and concrete examples written for the job.
- **Job log:** Posting, contact details and fields ready to transfer.

The application pack also includes its status and a saved next step.

## A check in practice

A demo pack initially passed validation. After one line in the CV changed, the tool rejected the previous review. The trial used fictional data. The content still needs to be assessed.

## A possible task at your workplace

I would like to use the same approach for a small, recurring task. For example, preparing a status note from project documents: gather sources, draft the note and have the project lead assess its content.

## My role

I set the direction and describe the requirements. I read the documents before they are sent. The AI assistant helps with research, text and code, and runs the checks.
